# Assets du projet AMH Caisse

Ce dossier regroupe les visuels utiles au projet afin d'eviter de laisser des fichiers isoles dans
le dossier parent `Stage`.

## Menu

- `menu/flyers/current/` : flyers definitifs utilises comme source de verite pour le catalogue de
  caisse.
- `menu/archive/ancienne-carte-2026-06/` : ancienne carte conservee pour historique et comparaison.
- `menu/site/` : exports visuels prevus pour le site internet.
- `menu/delivery/` : exports de travail pour plateformes de livraison.

## Impression

- `printing/manual/excelvan-thermal-receipt-printer/` : photos du mode d'emploi de l'imprimante
  thermique recue.
- `printing/examples/` : photos de tickets papier servant de reference de mise en forme, dont
  `ticket-cuisine-oeuf-2026-07-12.jpg` conserve le cas de regression ou `Oeuf` etait tronque a
  l'impression et `ticket-cuisine-libelle-long-2026-07-17.jpg` le cas ou `Pommes de terre` etait
  coupe sur deux lignes. Les fichiers `ticket-cuisine-police-double-trop-grande-2026-07-17.jpg` et
  `tickets-police-normale-trop-petite-2026-07-20.jpg` encadrent les deux tailles de police refusees
  et justifient le reglage intermediaire utilise par l'application.

## Interface

- `ui/examples/` : photos de defauts d'interface constates sur la tablette physique. Le fichier
  `panneau-livraison-non-repliable-2026-07-17.jpg` documente le panneau livraison qui masquait le
  contenu du panier et le champ telephone lors de l'ouverture du clavier.
