# Modèle d’attestation individuelle (éditeur)

> À remplir et signer **hors dépôt git** (PDF signé). Ne pas committer de signature scannée sensible si politique interne l’interdit ; conserver l’original chez l’éditeur.

Conformément au modèle d’attestation prévu par l’administration fiscale (CGI art. 286-I-3° bis) :

**Je soussigné(e)** : _______________________________  
**Agissant en qualité de** : représentant de l’éditeur  
**Atteste que le logiciel / système de caisse** :

- Nom : **Kebaba Caisse**
- Version : **________** (versionName / versionCode / hash APK)
- Éditeur : **________________**
- Date : **____ / ____ / ________**

respecte les conditions d’**inaltérabilité**, de **sécurisation**, de **conservation** et d’**archivage** des données (critères ISCA).

Cette attestation concerne **uniquement** la version ci-dessus. Une version majeure nouvelle nécessite une **nouvelle** attestation.

Signature : _______________________________

---

**Interdit** : utiliser la marque / logo « Certifié NF525 » sans certificat d’organisme accrédité.
